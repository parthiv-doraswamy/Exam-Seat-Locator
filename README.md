# 🎓 CBIT Exam Seat Locator

A simple and efficient web-based exam seating management system developed to help students quickly locate their exam hall and seat number using their hall ticket number.

The system is designed for university examination branches to simplify seating management and improve accessibility for students during examinations.

---

# 📌 Features

✅ Hall Ticket Based Search
✅ Fast Seat Lookup System
✅ CSV-Based Seating Data Import
✅ Responsive User Interface
✅ Lightweight Frontend Architecture

# ⚙️ How It Works

1. Student enters hall ticket number.
2. JavaScript reads and processes seating data from the CSV file.
3. Matching student details are searched dynamically.
4. Exam hall, seat number, and block details are displayed instantly.
