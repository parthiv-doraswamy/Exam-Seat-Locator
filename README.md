# University Exam Seat Locator

A web-based exam seating management system that enables students to search and locate their exam hall and seat number using hall ticket details.

## Features

- Hall ticket based seat search
- CSV-based seating data import
- Responsive UI
- Fast seat lookup functionality
- Clean dashboard interface

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project
2. Open the folder in VS Code
3. Run using Live Server
4. Search using sample hall ticket numbers
